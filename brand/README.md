# Brand kit

Surveyor's terminal: a field notebook for Next.js routes.

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#10140F` | backgrounds, app icon |
| Paper | `#EDE6D2` | type on dark, print |
| Lime | `#D6FF3F` | signal, `[slug]`, CTAs |
| Copper | `#C45C26` | map fold, highlights |
| Route | `#3DDC97` | GET methods |
| Dynamic | `#F5C542` | `[param]` |
| Catch-all | `#E879F9` | `[...slug]` |
| Group | `#60A5FA` | `(route-group)` |
| Error | `#FF5C5C` | DELETE, error UI |

## Files

- `mark.svg` / `mark.jpg` — app icon
- `logo.svg` — wordmark lockup
- `og.jpg` — Open Graph / GitHub social preview
- `index.html` — live kit
- `colors.css` — tokens

Type: Instrument Serif for the name, IBM Plex Mono for commands and tables.
